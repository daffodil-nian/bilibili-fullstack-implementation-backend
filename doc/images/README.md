# 图片资源目录（毕设用）

请将下列导出图放在本目录，并在 `doc/毕设/*.md` 中用相对路径引用。

| 建议文件名 | 内容 |
|---|---|
| `er-overview.png` | 总体 E-R 图 |
| `er-user.png` | 用户 / 钱包 / 关注 |
| `er-article.png` | 专栏及互动、评论 |
| `architecture.png` | 系统架构图 |
| `usecase.png` | 用例图 |
| `test-*.png` | 测试运行截图 |

引用示例（在 `03-数据库设计.md` 中）：

```markdown
![总体 E-R 图](../images/er-overview.png)
```

可用工具：draw.io、ProcessOn、StarUML、PowerDesigner 等。
