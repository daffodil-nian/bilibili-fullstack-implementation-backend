## 1. 技术选型

| 层次 | 技术 | 用途 |
|---|---|---|
| 语言 / 运行时 | Java 21 | 业务开发 |
| 框架 | Spring Boot 3.x | Web、依赖注入、测试 |
| ORM | MyBatis-Plus | MySQL 访问 |
| 数据库 | MySQL | 业务持久化 |
| 缓存 | Redis + Redisson | Token、专栏点击计数等 |

```text
                    ┌─────────────┐
                    │  前端 / 测试 │
                    └──────┬──────┘
                           │ HTTP
                    ┌──────▼──────┐

                    │   Service   │  业务：发布、详情、搜索 ...

```

## 5. 关键设计决策（写论文「特色」可用）

1. **用户双 ID**：`user.u_id`（对外 UID）与 `user.id`（内部/钱包）；专栏互动多用 `u_id`，钱包挂 `id`。  
2. **点击量写缓冲**：详情访问 Redis `INCR`，减轻 MySQL 压力（见 Redis 笔记）。  
3. **搜索与详情分离**：列表/搜索走 ES；正文详情走 MySQL。  
4. **互动拆表**：点赞 / 投币 / 收藏 / 转发各自关系表 + 主表冗余计数。
