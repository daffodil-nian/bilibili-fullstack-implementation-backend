## 1. 设计说明

1. 用户资料与钱包分离：`user` + `user_wallet`。  
2. 专栏互动采用「关系表 + 主表计数」：便于查「我是否赞/投/藏」与展示总数。  
3. 专栏作者关联 `user.u_id`；钱包主键关联 `user.id`（实现投币时注意转换）。  
4. 读者收藏用 `article_favorite`，与专栏上的 `collection_id`（作者文集）不是同一概念。

## 3. 主要数据表

### 3.1 用户与账户

| 表名 | 说明 | 关键字段 |
|---|---|---|
| `user` | 用户资料 | `u_id` 对外 UID；`id` 内部主键；账号密码昵称头像等级等 |
| `user_wallet` | 钱包 | `user_id`→`user.id`；`coin` 硬币；`b_coin` B 币 |
| `user_follow` | 关注关系 | `user_id`、`follow_id`、`status` |
| `wx_msg` | 微信相关消息 | 扩展用 |

### 3.2 专栏主数据

| 表名 | 说明 | 关键字段 |
|---|---|---|
| `articles` | 专栏主表 | 标题封面摘要正文；`status`；`like/comment/click/share/coin/favorite_count` |
| `article_category` | 分类 | `name`、`sort`、`status` |
| `article_tag` | 标签字典 | `name` 唯一 |
| `article_tag_relation` | 专栏-标签 | `article_id` + `tag_id` 唯一 |

**`articles.status`（与枚举对齐）：** 0 草稿，1 已发布，2 审核中，3 已下架，4 私密（以代码枚举为准）。

### 3.3 专栏互动

| 表名 | 说明 | 约束要点 |
|---|---|---|
| `article_thumb` | 点赞 | `UNIQUE(article_id, user_id)`，可 toggle |
| `article_coin` | 投币 | `UNIQUE(article_id, user_id)`；`coin_num` 默认 1；扣钱包 |
| `article_favorite` | 收藏 | `UNIQUE(article_id, user_id)`，可 toggle |
| `article_share` | 转发流水 | 可多次；展示可用 `share_count` |

### 3.4 评论

| 表名 | 说明 | 关键字段 |
|---|---|---|
| `article_comment` | 评论 | `root_comment_id`（一级=0）；`to_comment_id`；`reply_to_user_id` |
| `article_comment_thumb` | 评论点赞 | `UNIQUE(comment_id, user_id)` |

## 4. 与 Redis / ES 的分工（非关系表，论文可写）

| 存储 | Key / 索引 | 作用 |
|---|---|---|
| Redis | `article:click:aid_{id}` | 详情点击原子计数 |
| Redis | `user:token:uid_{id}` | 登录 Token |
| ES | 专栏文档（如 `bili_column`） | 标题等搜索，非正文详情源 |

## 5. 已有库增量注意

若库是早期 `CREATE TABLE` 建的，**不会自动出现新列**。新增 `coin_count` / `favorite_count` 及新表时需执行 `ALTER` / `CREATE`（见 `user.sql` 文末注释）。
