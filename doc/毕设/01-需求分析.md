# 01 需求分析

> 项目：仿 Bilibili 系统（后端 `bilibilimock-background`）  
> 更新日期：2026-08-30

---

## 1. 项目背景（可作论文引言素材）

面向学习与毕设演示，实现类 B 站核心能力的后端服务：用户账号、专栏内容、搜索与互动等。重点锻炼 Spring Boot 分层、MySQL 建模、Redis 热点计数、Elasticsearch 搜索等能力。

---

## 2. 用户角色

| 角色 | 说明 |
|---|---|
| 游客 | 部分接口可访问（如搜索白名单）；专栏私密内容不可见 |
| 登录用户 | 登录后可看详情、点赞/投币/收藏（规划中）、发评论（规划中） |
| UP 主 / 作者 | 发布专栏、管理自己的草稿/私密内容；看自己文章时有权限 |

## 4. 用例简述（写论文可画用例图）

### 用例：用户登录
- 参与者：用户  
- 前置：已注册  
- 主成功场景：输入账号密码 → 校验 → 返回登录凭证  

### 用例：发布专栏
- 参与者：登录用户  
- 主成功场景：填写标题封面摘要正文标签 → 校验 → 入库 →（已发布）写 ES → 返回文章 ID  

### 用例：查看专栏详情
- 参与者：登录用户 / 作者  
- 主成功场景：校验可见性 → Redis 点击 +1 → 组装详情 VO（作者、标签、是否已赞等）→ 返回  
- 扩展：私密且非作者 → 拒绝  

### 用例：投币（规划）
- 参与者：登录用户  
- 主成功场景：校验余额与是否已投 → 扣 `user_wallet` → 写 `article_coin` → `coin_count`+  

---

## 5. 非功能需求（可简写进论文）

| 类别 | 要求 |
|---|---|
| 性能 | 详情点击等高频写走 Redis，避免每次打 MySQL |
| 一致性 | 点击量 Redis 与 DB 最终一致；投币与扣款同一事务 |
| 安全 | 密码密文；接口登录拦截；私密专栏鉴权 |
| 可维护 | Controller / Service / Mapper 分层；SQL 集中 `sql/user.sql` |
