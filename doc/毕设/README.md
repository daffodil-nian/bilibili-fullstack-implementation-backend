# 毕设文档目录说明

本目录用于毕业设计过程材料积累，减轻后期写论文负担。  
**建表 SQL 权威来源仍是：** `sql/user.sql`  
**E-R / 架构 / 界面截图放：** `doc/images/`

| 文档 | 用途 | 对应论文章节（常见） |
|---|---|---|
| [01-需求分析.md](./01-需求分析.md) | 角色、功能、用例 | 需求分析 |
| [02-总体设计.md](./02-总体设计.md) | 技术栈、分层、架构 | 总体设计 |
| [03-数据库设计.md](./03-数据库设计.md) | 表说明、E-R | 数据库设计 |
| [04-接口设计.md](./04-接口设计.md) | API、入参出参 | 详细设计 / 接口 |
| [05-测试记录.md](./05-测试记录.md) | 用例与结果 | 系统测试 |
| [06-开发日志.md](./06-开发日志.md) | 按日进度 | 实现过程 |

### 使用约定

1. 每完成一个模块，当天补几行到 `05`、`06`，表有变更同步 `03`。  
2. E-R 图用 draw.io / ProcessOn 绘制后导出 png，保存为 `doc/images/er-xxx.png`，在 `03` 中引用。  
3. 学习笔记（如 `doc/06-Redis操作笔记.md`）可作「关键技术」素材，写论文时摘录，不必整篇搬进正文。  
4. **本目录只维护文档，不替代代码与 SQL。**
